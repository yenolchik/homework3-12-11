Main Git commands

  • git status - відображає поточний стан змін та файлів
  • git add - додає файли до індексу для наступного коміту
  • git commit - створює коміт з доданих файлів
  • git push - відправляє коміти на віддалений репозиторій
  • git branch - відображає список гілок репозиторію
  • git checkout - перемикається між гілками або створює окрему гілку
  • git clone - створює копію віддаленого репозиторію на комп'ютері
  • git config - налаштовує параметри репозиторію
  • git version - відображає версію Git
  • git pull - отримує оновлення з віддаленого репозиторію
  • git remote - відображає список віддалених репозиторіїв
